# דף נחיתה – Fashion Week Tel Aviv 2026 · אורט סינגאלובסקי

דף הזמנה לבנות שכבת י' עם רישום להסעה (יציאה מבית הספר ב־14:30 בדיוק, 9.11.26).

| קובץ | תפקיד |
|---|---|
| `index.html` | דף הנחיתה ודף הרישום (`#register`) |
| `assets/` | תמונת המסלול וההזמנה |
| `apps-script.gs` | קוד ששומר את ההרשמות בגיליון Google Sheets |

## חיבור הרישום לגיליון (פעם אחת, כ־5 דקות)

1. פותחים את הגיליון שכבר הוכן: [הרשמות הסעה – שבוע האופנה ת"א 2026](https://docs.google.com/spreadsheets/d/1SRAFAGCxLjkL575M2STZ4oLxvGazxblMc-9upPQdiPg/edit). יש בו לשונית "הרשמות" עם כותרות ולשונית "סיכום לפי כיתה".
2. בתפריט: **תוספים ← Apps Script**. מוחקים את מה שיש ומדביקים את כל התוכן של `apps-script.gs`. שומרים.
3. **פריסה (Deploy) ← פריסה חדשה ← סוג: Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. מאשרים את ההרשאות ומעתיקים את כתובת ה־Web app (מסתיימת ב־`/exec`).
5. ב־`index.html` מדביקים את הכתובת כאן:
   ```js
   const CONFIG = { endpoint: "https://script.google.com/macros/s/XXXX/exec" };
   ```

כל עוד הכתובת ריקה, הדף עובד במצב תצוגה ומציין שהפרטים לא נשמרים.

הגיליון מקבל לשונית "הרשמות" עם: תאריך הרשמה, שם פרטי, שם משפחה, ת"ז, טלפון, כיתה.
תלמידה שנרשמת פעמיים עם אותה ת"ז מעדכנת את השורה שלה ולא נוספת שוב.
