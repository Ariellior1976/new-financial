# מי בבית? נעילת הבריח לאחרון שנכנס

כל טלפון מדווח לשרת קטן כשהוא מתחבר לרשת `Barkai_2.4` וכשהוא מתנתק ממנה. השרת שומר מי בבית. כשבן הבית החמישי נכנס, ורק הוא, קופצת אצלו על המסך ההודעה "כולם בבית. נעל/י גם את הבריח".

אין אפליקציה להתקין מחנות. השרת רץ בחינם ב-Google Apps Script, באייפונים הדיווח עובר דרך אפליקציית "קיצורים" (Shortcuts) שמובנית במכשיר, ובסמסונג דרך MacroDroid.

## שלב 1: השרת (פעם אחת, מהמחשב)

1. נכנסים ל-https://script.google.com עם חשבון גוגל ולוחצים "פרויקט חדש".
2. מוחקים את מה שכתוב שם ומדביקים את כל התוכן של `Code.gs`. שומרים.
3. בתפריט מימין: הגדרות הפרויקט (גלגל שיניים) ← מאפייני סקריפט ← הוספה. שם: `SECRET`. ערך: מילה סודית ארוכה שתמציא, למשל `barkai-7Hq2pX9`. היא מונעת מזרים לשנות את הנתונים.
4. למעלה: פריסה (Deploy) ← פריסה חדשה ← סוג: אפליקציית אינטרנט.
   - ביצוע בתור: אני
   - למי יש גישה: כל אחד
5. מאשרים את ההרשאות שגוגל מבקש ומעתיקים את הכתובת שמסתיימת ב-`/exec`.

בדיקה: פותחים בדפדפן את הכתובת עם התוספת `?key=הסוד&action=status`. אמורה להופיע רשימה של חמשת בני הבית, כולם "בחוץ".

## שלב 2: הקוד של כל אחד

| בן בית | who |
|---|---|
| אבא | `abba` |
| אמא | `ima` |
| אריאל | `ariel` |
| ליאור | `lior` |
| אילי | `ili` |

כל טלפון משתמש בשתי כתובות (מחליפים את `URL`, `הסוד` ואת ה-who):

```
URL?key=הסוד&who=ariel&action=arrive
URL?key=הסוד&who=ariel&action=leave
```

## שלב 3: אייפון (אוטומציה ב"קיצורים")

אוטומציה ראשונה, כניסה הביתה:

1. קיצורים ← אוטומציה ← `+` ← Wi-Fi.
2. רשת: בוחרים `Barkai_2.4`. מסמנים "מצטרף" (Joins).
3. מסמנים "הפעל מיד" (Run Immediately) ומכבים "הודע בזמן הפעלה".
4. הבא ← אוטומציה ריקה ← מוסיפים פעולות:
   - "קבל תוכן של URL" (Get Contents of URL) עם כתובת ה-`arrive`.
   - "אם" (If): תוכן ה-URL מכיל `בריח`
     - בתוך ה"אם": "הצג עדכון" (Show Notification) עם תוכן ה-URL.

אוטומציה שנייה, יציאה:

1. אותו דבר, אבל מסמנים "עוזב" (Leaves) במקום "מצטרף".
2. פעולה אחת בלבד: "קבל תוכן של URL" עם כתובת ה-`leave`.

## שלב 4: סמסונג (MacroDroid)

1. מתקינים את MacroDroid מ-Google Play (הגרסה החינמית מספיקה לשני מאקרו).
2. מאקרו ראשון, כניסה:
   - טריגר: Wi-Fi State Change ← Connected to Network ← `Barkai_2.4`.
   - פעולה: HTTP Request, שיטה GET, כתובת ה-`arrive`. בלשונית התגובה שומרים את גוף התשובה (Response body) למשתנה טקסט חדש בשם `resp`.
   - פעולה: If ← Variable `resp` contains `בריח` ← Display Notification עם הטקסט `{v=resp}`.
3. מאקרו שני, יציאה:
   - טריגר: Wi-Fi State Change ← Disconnected from Network ← `Barkai_2.4`.
   - פעולה: HTTP Request עם כתובת ה-`leave`.
4. בהגדרות האנדרואיד מבטלים את חיסכון הסוללה עבור MacroDroid (הגדרות ← אפליקציות ← MacroDroid ← סוללה ← ללא הגבלה). אחרת סמסונג עלול לעצור אותו ברקע.

## שלב 5: הפעלה ראשונה

כולם צריכים להיות מסומנים נכון בהתחלה. מי שבבית מתנתק מה-WiFi ומתחבר שוב אחרי 5 דקות לפחות, או פשוט פותח בדפדפן את כתובת ה-`arrive` שלו. בודקים עם `action=status` שהרשימה נכונה.

## איך זה מתנהג

- רק מי שמשלים את החמישה מקבל את ההודעה. מי שנכנס כשעדיין חסר מישהו לא מקבל כלום.
- אייפון מתנתק לפעמים מה-WiFi לכמה דקות כשהוא בשינה. חזרה שמגיעה פחות מ-5 דקות אחרי ההתנתקות לא נחשבת לכניסה, כך שאף אחד לא יקבל הודעת נעילה ב-3 לפנות בוקר בלי שנכנס. אפשר לשנות את המספר ב-`RECONNECT_GRACE_MINUTES`.
- אם יש בבית גם רשת 5GHz שהטלפונים מתחברים אליה, צריך לבחור באוטומציות גם אותה. `Barkai_Dreame` היא כנראה הרשת של שואב האבק, ואין צורך לבחור בה.
- מי שיוצא ושוכח את הטלפון בבית נשאר מסומן "בבית". אם זה קורה, ההודעה עלולה להגיע כשהוא עדיין בחוץ. כדאי להגיד את זה לכולם.
