# הגדרת סמסונג עם MacroDroid, צעד אחרי צעד

המדריך נכתב בזמן הגדרה אמיתית על סמסונג, עם MacroDroid בעברית (נובמבר 2026). שמות המסכים והכפתורים הם כפי שהופיעו בפועל. במקומות שבהם ההוראות הכלליות לא התאימו למה שהופיע על המסך, זה מצוין בהערה "שים לב".

## מה צריך להכין מראש

- כתובת השרת שמסתיימת ב-`/exec`. במחשב, בפרויקט ב-script.google.com: "לפריסה" ← "ניהול פריסות" ← מעתיקים את "כתובת URL של אפליקציית אינטרנט".
- המילה הסודית (מאפיין הסקריפט `SECRET`).
- שתי כתובות מלאות, שנשלחות לטלפון בווטסאפ לעצמך ומשם מעתיקים:
  ```
  https://script.google.com/macros/s/.../exec?key=הסוד&who=abba&action=arrive
  https://script.google.com/macros/s/.../exec?key=הסוד&who=abba&action=leave
  ```
  (מחליפים את `abba` ב-who של בעל הטלפון.)

שים לב: אין להעתיק את הכתובת מסרגל הכתובות אחרי שדף הבדיקה נטען. הדפדפן עובר לכתובת שמתחילה ב-`script.googleusercontent.com/macros/echo`, והיא לא מתאימה. צריך את הכתובת שמתחילה ב-`script.google.com/macros/s/` ומסתיימת ב-`/exec`.

## התקנה

מתקינים את "מאקרו-דרואיד - אוטומציה" (MacroDroid) של ArloSoft מ-Google Play. הגרסה החינמית מספיקה לשני מאקרו.

## מאקרו 1: "הגעתי הביתה!"

### טריגר

1. במסך הבית של MacroDroid: "הוסף מאקרו" (`+`).
2. בפס האדום "טריגרים": `+` ← "קישוריות" ← "שינוי מצב Wi-Fi" ← "מחובר לרשת" ← מסמנים `Barkai_2.4` ← אישור.
3. אם מתבקשת הרשאת מיקום, בוחרים "אפשר כל הזמן". בלי ההרשאה הזו אנדרואיד לא מגלה לאפליקציה את שם הרשת.

שים לב: בדקו שיש בפס האדום טריגר אחד בלבד. אצלנו הוא נוסף פעמיים בטעות. מוחקים כפילות בלחיצה על הטריגר ← מחיקה.

### משתנה לתשובה

4. בפס התחתון "משתנים מקומיים": `+` ← שם `resp` ← סוג "מחרוזת".

### פעולה 1: בקשת HTTP

5. בפס הכחול "פעולות": `+`, ובחיפוש (זכוכית מגדלת) כותבים `HTTP` ← "בקשת HTTP".

   שים לב: הפעולה לא נמצאת תחת "קישוריות". היא בקטגוריה "אינטראקציות אינטרנט", אבל הכי מהיר למצוא אותה בחיפוש.

6. בלשונית "הגדרות":
   - שיטת בקשה: `GET`
   - הזן כתובת אתר: מדביקים את כתובת ה-`arrive`.
   - מסמנים "חסום את הפעולות הבאות עד להשלמה". בלי הסימון הזה, ה"אם" רץ לפני שהתשובה הגיעה.
   - "עקוב אחר הפניות מחדש" צריך להיות מסומן (ברירת מחדל). גוגל מפנה את הבקשה לכתובת אחרת.
   - "אפשר כל תעודת אבטחה" נשאר לא מסומן.
7. גוללים לתחתית אותה לשונית, מתחת ל"תעודת לקוח (mTLS)" ו"פרוקסי", לחלק "תגובה":
   - "שמור קוד סטטוס" ו"שמור כותרות": משאירים "אל תשמור פלט".
   - "שמור תגובה": בוחרים "שמור את תגובת השרת במשתנה מחרוזת" ← `resp`.
8. ✓ למעלה משמאל.

שים לב: שני האייקונים עם החצים בפס העליון של מסך בקשת ה-HTTP לא קשורים לשמירת התגובה. החץ שנכנס לריבוע הוא "ייבוא ממחרוזת cURL" (לוחצים "ביטול"). החץ שיוצא מהריבוע הוא "ייצא למחרוזת curl". הייצוא שימושי כדי לראות את הכתובת המלאה ולוודא שאין בה טעות.

### פעולה 2: תנאי

9. `+` בפס הפעולות ← "תנאים/לולאות" ← "בדיקת תנאי (If)".
10. בחלון "בדיקת תנאי": `+` ליד "תנאים" ← "ייחודי ל-MacroDroid" ← "משתנה מאקרו-דרואיד" ← `resp` ← "מכיל" ← כותבים `בריח` ← אישור.
11. אפשר לסמן "אל תרשום כישלון תנאי אם התנאי אינו מתקיים" (כדי שהיומן לא יתמלא, כי ברוב הכניסות התנאי לא מתקיים) ← אישור.

MacroDroid מוסיף לבד שתי שורות: "אם" ו"סוף תנאי".

### פעולה 3: ההודעה

12. `+` בפס הפעולות ← קטגוריה "התראה" ← "התראה".
13. אם קופץ חלון "טקסט קסם", זה רק הסבר. לוחצים אישור.
14. ממלאים:
    - כותרת: `בריח`
    - טקסט התראה: `כולם בבית. נעל/י גם את הבריח`
    - מסמנים "התראה מתמשכת" (נשארת עד שלוחצים עליה).
    - שאר האפשרויות כבויות ← אישור.

שים לב: אין צורך להכניס את המשתנה `resp` לטקסט. ההתראה רצה רק כשהתנאי מתקיים, אז טקסט קבוע מספיק.

אפשרות חלופית: "הצגת דיאלוג" באותה קטגוריה פותחת חלון באמצע המסך, בולט יותר מהתראה.

### סדר הפעולות

15. ההתראה צריכה להיות בין "אם" ל"סוף תנאי". אצלנו היא נוספה אחרי "סוף תנאי", ובמצב כזה היא הייתה קופצת בכל כניסה. מתקנים עם כפתור החצים (⇅) בפס הכחול וגרירה, ושוב ⇅ כדי לצאת ממצב הסידור.

הסדר הסופי:
```
בקשת HTTP (GET)
אם  resp מכיל בריח
    התראה  כולם בבית. נעל/י גם את הבריח
סוף תנאי
```

### שם ושמירה

16. "הזן שם מאקרו" למעלה ← `הגעתי הביתה!`.
17. שלוש נקודות ← "שמור שינויים".

## מאקרו 2: "יצאתי מהבית!"

1. חוזרים עם החץ (→) למסך "מאקרו" ולוחצים `+` למטה.
   (אפשר גם לשכפל את המאקרו הראשון בלחיצה ארוכה ← "שכפל", ואז לשנות את הטריגר ואת סוף הכתובת, ולמחוק את התנאי וההתראה.)
2. טריגר: "קישוריות" ← "שינוי מצב Wi-Fi" ← "מנותק מרשת" ← `Barkai_2.4`.
3. פעולה ראשונה, המתנה: `+` ← בחיפוש כותבים `המתן` ← "המתן לפני הפעולה הבאה" (תחת "מאקרו", אייקון zzz) ← 30 שניות, "השתמש בשעון מעורר" מסומן ← אישור.

   שים לב: "המתן לטריגר" (תחת "ייחודי ל-MacroDroid") הוא משהו אחר. לא לבחור בו.

4. פעולה שנייה: "בקשת HTTP" עם כתובת ה-`leave`. כאן לא צריך לשמור תגובה ולא צריך "חסום את הפעולות הבאות".
5. לוודא שההמתנה לפני בקשת ה-HTTP. אפשר לבדוק עם "ייצא למחרוזת curl" שהכתובת מסתיימת ב-`action=leave`.
6. שם: `יצאתי מהבית!` ← שלוש נקודות ← "שמור שינויים".

למה ההמתנה: בבדיקה הראשונה, אחרי כיבוי ה-WiFi, השרת לא עודכן. הבקשה נשלחה ברגע הניתוק, לפני שהטלפון עבר לגלישה סלולרית, ונכשלה בלי הודעת שגיאה. אחרי שהוספנו 30 שניות המתנה, העדכון עבר.

## הגדרות טלפון

- הגדרות ← אפליקציות ← MacroDroid ← סוללה ← "ללא הגבלה".
- הגדרות ← אפליקציות ← MacroDroid ← הרשאות ← מיקום ← "אפשר כל הזמן".
- ברשימת המאקרו לוודא שהמתגים של שני המאקרו ושל "ללא קטגוריה" דלוקים. הסינון "מאופשר" מראה רק מאקרו פעילים.

## בדיקה

1. יציאה: מכבים את ה-WiFi, מחכים דקה, ובודקים את כתובת ה-status. אמור להופיע "בחוץ". (עבד.)
2. כניסה: מחכים לפחות 5 דקות, מדליקים את ה-WiFi, מחכים חצי דקה ובודקים שוב. אמור להופיע "בבית". אם לא, מוסיפים גם ל"הגעתי הביתה!" "המתן לפני הפעולה הבאה" של 10 שניות לפני בקשת ה-HTTP.

בדיקה בלי לגעת ב-WiFi: בתוך מאקרו ← שלוש נקודות ← "בדוק פעולות". זה מריץ את הפעולות מיד.
